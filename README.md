# LF10 Game

Ein 2D-Game, das im Rahmen von LF10 entwickelt wird.

Das Projekt besteht aus einem Python-Backend und einem JavaScript-Frontend. Das Backend kümmert sich unter anderem um Benutzerkonten, Sessions und das Speichern des Spielfortschritts.

## Projektstruktur

```text
LF10_Game/
├── Backend/
│   └── ...
│
├── Frontend/
│   └── ...
│
├── .gitignore
├── README.md
└── requirements.txt
```

## Status

Das Backend für Benutzerverwaltung und Spielfortschritt ist bereits funktionsfähig.

Die Entwicklung des 2D-Frontends und der Oberwelt befindet sich noch im Aufbau.
